# Боевая система в Roguelike

## Из чего состоит?
Система ИИ врагов включает в себя:

EnemyAIComponent - основной компонент ИИ, отвечает за принятие решений, преследование игрока и атаки

TransformComponent - предоставляет позицию и вращение объекта в мире

RigidbodyComponent - управляет физическим движением врага

AttackComponent - отвечает за нанесение урона и параметры атаки

HealthComponent и ArmorComponent - управление здоровьем и бронёй врага

Возможности:
Преследование игрока - враг отслеживает позицию игрока и движется к нему

Тактическое поведение - поддержание дистанции атаки, остановка для совершения атак

Система зрения - ограниченный радиус обнаружения игрока

Координация атак - перезарядка между атаками для баланса геймплея

Приоритет целей - фокусировка на игроке как основной цели

Характеристики ИИ:
movementSpeed - скорость перемещения врага

attackRange - дистанция на которой враг может атаковать

visionRange - радиус обнаружения игрока

attackCooldown - время перезарядки между атаками

attackCooldownTime - базовое время перезарядки

Управление поведением:
EnemyAIComponent содержит методы для настройки поведения:

SetTarget(GameObject* target) - установка цели для преследования

SetMovementSpeed(float speed) - настройка скорости движения

SetAttackRange(float range) - установка дистанции атаки

SetVisionRange(float range) - настройка радиуса обнаружения

CanAttack() - проверка возможности атаковать (завершена ли перезарядка)

Механика работы:
Обнаружение цели - каждое обновление проверяется расстояние до игрока

Принятие решения - если игрок в радиусе зрения, выбирается поведение:

Преследование - движение к игроку с адаптивной скоростью

Атака - остановка и нанесение урона при достижении дистанции атаки

Ожидание - если игрок вне радиуса зрения

Координация атак - система перезарядки предотвращает спам атаками

Пример создания врага:

Для создание врага необходимо:

1.Создать объект для врага и добавить следующие компоненты: TransformComponent, SpriteRendererComponent, RigidbodyComponent, SpriteColliderComponent, AttackComponent, HealthComponent,ArmorComponent,EnemyAIComponent.
2.Ввести характеристики health->SetHealth(50);attack->SetDamage(10);armor->SetArmor(3); attack->SetRange(70.0f);.
3.Настроить ИИ компонент ai->SetTarget(player->GetGameObject()); ai->SetMovementSpeed(120.0f); ai->SetAttackRange(70.0f);ai->SetVisionRange(250.0f);.
4.Добавить HUD для врага компонентами HealthBarComponent и ArmorBarComponent


Сценарий поведения:
Игрок входит в радиус зрения (250 units) - враг начинает преследование

Игрок входит в радиус атаки (70 units) - враг останавливается и атакует

Атака наносит урон - учитывается броня игрока через ArmorComponent::ReduceDamage()

Активируется перезарядка - враг не может атаковать 1 секунду

Игрок выходит из радиуса - враг прекращает преследование и переходит в режим ожидания

Балансировка:
Скорость движения (120 units/sec) - позволяет игроку уходить от преследования

Радиус атаки (70 units) - требует тактического позиционирования

Перезарядка (1 second) - даёт игроку окно для контратаки

Здоровье и броня - балансируются относительно урона игрока
