# 2D Roguelike с собственным движком на C++

Игровой проект в жанре Roguelike с собственным движком на C++ с использованием SFML. в игре
предстоит бегать по случайно сгенерированному лабиринту, населеному монстрами и пытается спастись,а спастись не удасться,потому что разработчик не смог.

## Roguelike
- Генерация процедурных уровней 
- Враги c ИИ 
- Характеристики персонажа и врагов

## Engine
GameWorld (менеджер объектов)
ResourceSystem (ресурсы)
PhysicsSystem (физика)
RenderSystem (графика)

## Установка и запуск
Вариент 1:
1. Клонируйте репозиторий:

2. Откройте Game.sln в Visual Studio

3. Соберите и запустите проект (F5)

## Используемые технологии

- C++17

- SFML 2.5.1

- Visual Studio 2022
